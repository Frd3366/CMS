# Project Agent Instructions (CTSO Management System)

For any UI, layout, copy, or code comment work in this repository:
1. Read `DESIGN.md` first for brand identity, color palette, typography, radius hierarchy, liveliness dials (`Dial: ENERGY 1 / RHYTHM 2 / MOTION 1`), and one-line design reasons.
2. Apply `.agents/skills/ui-ux-pro-max/SKILL.md` (along with `design-system`, `ui-styling`, `design`, `brand`, `slides`, and `banner-design`) for UI/UX design intelligence, palettes, typography, UX rules, and stack guidelines.
3. Apply `.agents/skills/antislop/SKILL.md` (together with `antislop-ui`, `antislop-copywriting`, `antislop-code`, `antislop-layoutmobile`, and `antislop-human`) as the mandatory filter and run the Delivery Gate before delivering.
